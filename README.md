# CaitaKenchikuClub.github.io

けんちくぶ！のウェブサイト（GitHub Pages のユーザーサイト）。公開 URL：https://caitakenchikuclub.github.io/

- `index.html`：紹介ページ（Google Play の「ウェブサイト」欄に登録する）
- `burokocho/index.html`：ブロッ校長！の遊び方ページ（AdSense の審査用の文章ページも兼ねる。2026-10-17 追加）。画像 `assets/img/burokocho-chara.webp` はゲームのキャラ画像（Caita建築部）
- `ads.txt`：AdSense の ads.txt（Web 版の広告用。2026-10-17 追加）。**このファイルの場所（サイトの一番上）と中身を変えない**
- `index.html`・`burokocho/index.html` の `<head>` に AdSense のコード（サイトの確認と審査用）。AdSense の「自動広告」はオフのままにする（ゲームのページに勝手に広告が出ないように）
- `app-ads.txt`：AdMob の app-ads.txt。**このファイルの場所（サイトの一番上）と中身を変えない**。AdMob のサイト運営者 ID（pub-9985841758256257）を Google に示す
- `assets/fonts/`：ブロッ校長！と同じフォント（SIL OFL 1.1。各フォルダの OFL.txt を消さない）
- `assets/img/kenchikubu-logo.webp`、`assets/icons/`：けんちくぶ！のロゴとブロッ校長！のアイコン（Caita建築部）
- `.nojekyll`：GitHub Pages の Jekyll 処理を止める空ファイル
